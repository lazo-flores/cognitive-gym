Assessment Practice

Practice the three gamified formats

Original practice items in the style of common gamified cognitive assessments (deductive-logic "switch" puzzles, timed mental-arithmetic digit puzzles, and dual-task memory grids). Difficulty ramps up as you build a streak, so it should feel hard the whole way through: in adaptive tests, that feeling means you are doing well.

Switch: work out the position code that transforms the top row into the bottom row. The code reads left to right: each digit tells you which TOP position the BOTTOM symbol came from.

Digit: fill the blanks so the equation is true. Each digit 1-9 can be used once per equation, including the digits already shown. Adjacent cells joined by an underline form one multi-digit number (tens then units): "2 4" reads as twenty-four, and two joined empty cells are one two-digit number you fill digit by digit. The real test uses the same convention. The clock is short on purpose.

Grid: memorize highlighted cells in order while solving symmetry and rotation questions in between, then click the memorized cells back in order.

Tip: practice each game until the mechanics feel boring. That is the goal; the real test's content will differ, but the formats will feel familiar.
